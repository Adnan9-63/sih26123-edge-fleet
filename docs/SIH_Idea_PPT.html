Fully Decentralized Edge-AI Fleet Coordination — No Cloud, No Central Server, Zero Collisions

  • Three-layer per-robot stack: P2P Comms → PIBT Conflict Resolution → Auction-based Task Allocation
  • Edge-AI layer: XGBoost congestion prediction + Isolation Forest anomaly detection, <2ms inference on Raspberry Pi
  • Air-gapped by design: Built for RF-degraded environments (military depots, hazardous warehouses) where cloud connectivity cannot be assumed.
  • USP: PIBT (IJCAI 2019) — mathematically proven deadlock-free conflict resolution, O(neighbors) per tick. Competitors use ad-hoc heuristics that deadlock in narrow corridors.

System Architecture & Tech Stack

Task Allocation (Contract Net Auction) ↓ Edge-AI (XGBoost + Isolation Forest) ↓ Path Planning (PIBT — deadlock-free) ↓ Comms (UDP Multicast P2P — no broker)
Component Technology Why
Path Planning PIBT (Okumura, IJCAI 2019) O(neighbors), deadlock-free, edge-compatible
Edge-AI XGBoost + Isolation Forest <50KB models, <2ms on ARM, no GPU needed
Communication UDP Multicast (P2P) Zero broker, zero SPOF, standard library only
Task Allocation Contract Net Protocol Decentralized bidding, no dispatcher
Dashboard Pygame + Browser Canvas Read-only observer, never controls fleet
Language Python 3.11+ ROS2-compatible, pip-installable on ARM Linux

Data flow: Robot senses → broadcasts intent via UDP → receives neighbors' intent → PIBT resolves conflicts locally → moves → repeats.

Why This Works on Real Edge Hardware

  • Performance: PIBT requires <1.5ms per tick per agent in Python on x86, easily fits 50Hz control loop on ARM Cortex-A72.
  • Ultra-Lightweight AI: 50KB XGBoost + 30KB Isolation Forest, total <100KB, runs without GPU.
  • Zero Overhead: No external dependencies beyond pip-installable packages — no ROS2 install required for simulation.
  • Hardware Agnostic: Same codebase deployable to Raspberry Pi 4 / Jetson Nano without modification.
  • Verified Correctness: 23/23 automated tests passing — algorithm correctness is continuously verified.

Risks & Mitigations

Risk Mitigation
UDP packet loss PIBT re-derives decisions every tick — stale data ages out in 2s
Edge-AI model corruption Graceful fallback to rule-based heuristics, no crash
Positional swap deadlock Task allocation layer prevents direct swap assignments
